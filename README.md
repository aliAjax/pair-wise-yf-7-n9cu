# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 词组连排

字模库下方可保存 2～6 个字的词组，列表中每条词组可以「应用」或「移除」。

- 应用前先在版面上点击一个格子作为起点（金色描边标记），词组会从该格起按当前阅读方向连续落字：横排向右、竖排向下。
- 每个字自动挑选一件字模：优先与当前选中字模同字同风格，其次取同字其它尚有库存的风格。
- 落字前整条预检，任一条件命中即整次拒绝，状态条会写明首个原因及对应字符，版面不留半截：
  - 任一落点越出纸张边界（不自动换行，不换行接续）；
  - 某个字在字模库中没有任何字模；
  - 某个字的全部风格字模都已用尽（词组内重复字会累计消耗）。
- 词组随草稿一并保存，载入草稿时恢复。
